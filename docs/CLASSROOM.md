# 课堂使用指南（中小学）

## 传感器一览

调色板「传感器」含：加速度、方向、定位、陀螺仪、接近、计步、光线、磁场、电量、网络、摇一摇。电脑预览是教学模拟器：摇一摇、定位、光线可用面板上的模拟值触发；定位/相机/通知会弹出允许/拒绝。电量/网络仍可读浏览器接口。案例「拓展·真机舱」「课题·摇动计数」已预装全套。嵌入约定见 [GOX-EMBED.md](GOX-EMBED.md)。课程半成品不放在编辑器里，由课页传入工程 JSON。

## AI 编程（可选）

左侧「AI」面板可对接 DeepSeek / OpenAI 兼容接口：在本机填写 API KEY（**不写入工程**），用自然语言「生成」或「纠错」页面与积木，确认后点「插入」覆盖当前项目。课堂若无外网或密钥，请继续用「学习 / 项目」里的案例。

## 角色分工

| 角色 | 做什么 |
|------|--------|
| 学生 | 电脑浏览器打开 IDE，设计界面与积木；教师机可直接导出 APK |
| 教师 | 维护「构建机」（`E:\ai2-build-env` + `npm run dev`），点「导出 APK」分发 |
| 教室网络 | 学生设计可不联网；装 APK 可用 U 盘 / 局域网共享 |

## 一节课流程建议（40–45 分钟）

1. **5 分钟**：打开「学习」面板，选定课题一句话  
2. **10 分钟**：用「简单」案例改界面文字与颜色  
3. **15 分钟**：积木实现 1～2 个事件（点击、拍照、存数）  
4. **5 分钟**：预览自测  
5. **5 分钟**：点「导出 APK」，教师机下载安装包  

## 数据与文件（记事本 / 搜索）

- **笔记库**：App 内置读写（预览用浏览器存储，APK 同步 Preferences），适合个人记事本。  
- **文件选择 / 文件夹**：由用户在手机或电脑上自己选文件，再搜索、展示、变换。  
- **文本工坊**：搜索行、替换、排序、去重、打乱、CSV 列、字数统计。  
- 案例：「记事本」「文件搜索」以及拓展·数据站。

详见组件「用法」说明与积木分类「笔记文件」「文本工坊」。

## 案例等级（约 3:4:2:2:1）

共 **39** 套案例，工程面板可按等级筛选。定级综合：**积木体量**（事件/分支/嵌套）、**概念负荷**（计时·存储·多屏·算法）、**一节课能否玩通**。拓展=组件展馆；娱乐=放松合集（不当主线台阶）。

| 等级 | 数量 | 适合 |
|------|------|------|
| 简单 | 9 | 弹幕加油、抛硬币、食堂打分、零食车、过马路、心情灯、狂点、表情聊天、幸运点名 |
| 中等 | 12 | 蓄力冲刺、霓虹钟、抢答、反应秒表、颜色记忆、口算、密码箱、分享、心情日记、电子宠物、掷骰对战、摇一摇 |
| 难 | 9 | 多屏导航、星际问答、涂鸦、石头剪刀布、文件特工、摇杆推球、绘本翻页、校园导览、任务链 |
| 拓展 | 6 | 五大展馆 + 拍照贴图 |
| 娱乐 | 3 | 派对盒子、占卜秀、迷你街机（限时吃星星） |

每个案例卡片可展开「查看指导说明」：怎么玩、课堂步骤、重点组件。  
内置媒体：`public/media/`（AI 示例图 / 音效 wav / 短视频 mp4），预览与导出均可离线使用；资源面板会列出「内置·…」。  
验收目标：调色板每个组件至少出现在 **3** 个案例中（`npm run verify:cases`）。

**重要**：预览严格按积木执行。骰子/硬币/交通灯/占卜球等点击后，只有积木里写了「掷骰子 / 抛硬币 / …」才会有动作；弄坏或清空积木后点它们不会再自动出结果（`npm run verify:blocks`）。

## 安全与隐私

- 作品中不要出现真实姓名、电话、住址、证件号  
- 仅申请课题需要的权限；拒绝权限后应有界面提示  
- Debug APK 仅课堂使用，勿上传到公开应用商店  

## 常见问题

**Q：电脑预览不能拍照？**  
A：正常。电脑会弹出选图；装成 APK 后才调系统相机。

**Q：学生电脑能自己打 APK 吗？**  
A：可以，但环境重。建议教师统一构建，降低门槛。

**Q：安装失败？**  
A：检查「未知来源」、存储空间、是否下载完整；可换一台测试机重装。
